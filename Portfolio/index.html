ENGINEERING HIGHLIGHTS

Crafted for Ultimate Audio & UI Performance

Designed with liquid glass aesthetics, real-time personalization, and robust audio state management.

Custom Theme Studio

Allows users to define custom primary, secondary, highlight, and background color schemes with real-time live preview and persistent anti-flicker loading.

Spotify-Style Playlist UI

Features dynamic 2x2 mosaic cover generation, hero header metadata, giant single-tap play/pause action bar, and quick track management.

Vinyl Turntable Interface

Interactive spinning turntable record modal with fluid tonearm animations, ambient artwork blurring, and full media control bindings.

Ringtone Studio

Select custom start positions and clip durations (15s, 30s, 45s) to generate, slice, and save audio ringtones directly to your device.

Generation-Locked Audio

Authoritative state machine architecture (`_playbackRequestId`) preventing stream duplication, race conditions, and mid-track playback stalls.

Screen-OFF Persistence

WebAudio keep-alive thread and native MediaSession handlers ensuring audio streams continuously when screen is locked or OFF.

TECHNOLOGY STACK

The latest release for Vibentra is v1.4.2, released on October 11, 2026.

Here is a summary of the latest updates and additions:

🎵 Audio & Playback

  • Bit-Perfect USB-DAC Output (#545): Direct audio passthrough to external USB DACs (supports UAC1 and UAC2 devices, automatic sample rate switching, and volume control).
  • Varispeed: Player setting that links pitch to playback speed for a tape-style speed-up/slow-down effect.
  • New Crossfade Engine: Smoother transitions using an equal-power curve with adaptive track prebuffering.
  • Enhanced Metadata Cleaning: Improves lyrics matching while preserving band names containing conjunctions/ampersands.

🔌 Extension Sources (Addons)

  • Third-Party Content Extensions: Allows adding custom addon server URLs to pull in third-party audio streams into Search and native playback.
  • Management Screen: Dedicated settings screen to toggle or manage individual addon sources with automatic URL scheme validation (https://).

🧠 Recommendations & AI Hub

  • Local Taste Engine (#542): Generates playlists directly on-device by evaluating play count, skip rates, likes, recency, time of day, and genre.
  • Daily Taste Mix: Background service that periodically refreshes the "My Taste Mix" playlist every 24 hours without creating duplicates.
  • Spotify Integration: Connect Spotify to fetch Spotify recommendation carousels alongside standard YouTube Music feeds.
  • "Never Recommend Again": Context menu option to permanently blacklist tracks from recommendations.
  • New AI Providers: Added Opper and API Route AI translation provider (#566).
  • Custom AI Models & Testing: Custom model naming, test connection buttons for OpenRouter/DeepL, and an increased generation timeout (90s).
  • Song DNA: Added smart Wikipedia fallbacks when metadata is missing.

🎨 UI & Appearance

  • Apple Music-Style Player Menu: Redesigned player options menu with frosted glass styling.
  • New Launcher Icons: Added community-requested launcher icons (Craft and Sadie Sink), circular icon masking, and alphabetical icon sorting.
  • Home Carousel Overhaul: Quick Picks carousel enlarged to 360dp to prevent cropping square album covers.
  • Ambient Mode Improvements: Lyrics remain centered in a 60% width block when album art is toggled off.
  • Artist Screen: Made the Subscribe button a standalone rounded pill button.

📳 Haptics Overhaul (#527)

  • Dedicated Haptics Menu: Comprehensive settings menu with intensity presets (Light, Medium, Strong).
  • Granular Vibration Toggles: Granular toggles for touch, long-press, slider scrubbing, and scroll-boundary edge vibrations.

🛠️ Architecture & Bug Fixes

  • Modularization (#550): Codebase refactored into :domain, :metadata, :dsp-core, and :audio-dsp modules.
  • Ktor Upgrade: Updated Ktor from 3.4.0 to 3.6.0.
  • Fixes:
    • Fixed playback stalling and loudness drops after network disconnects/reconnects. • Fixed streams cutting off prematurely before track ends. • Fixed UI desync between the play/pause button and crossfade/prebuffering. • Resolved issues with blurred lyrics in Ambient Mode and double-Enter required in Search.
